# Bar Management System Android App

A simple Android bar management application for tracking inventory, liquor sales, customer orders, supplier purchases, and revenue dashboards.

## Features
- Dashboard overview with summary cards
- Inventory management for beer, wine, spirits, mixers, and snacks
- Sales tracking for each transaction
- Live order monitoring for tables and customers
- Purchase order and supplier tracking
- Revenue and stock analytics
- Clean Material 3 UI

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3

## Project structure
- `app/src/main/java/com/zingayu/barmanagement` – app source
- `app/src/main/res` – Android resources

## Run locally
1. Open the project in Android Studio.
2. Let Gradle sync the project.
3. Run the app on an emulator or Android device.

## Notes
This app is designed as a practical starter for a bar business management system and uses in-memory sample data so it can run immediately without backend services.
